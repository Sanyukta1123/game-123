# 🎈 Balloon Pop Game

A fun and interactive browser-based game built using **HTML, CSS, and JavaScript**. The objective is to pop as many balloons as possible before the timer runs out.

---

## 📌 Features

- 🎈 Randomly appearing colourful balloons
- 🖱️ Click balloons to earn points
- ⏳ 30-second countdown timer
- ⚡ Increasing difficulty as the score increases
- 🎨 Attractive user interface with animations
- 🔄 Play Again button after the game ends
- 💻 Runs directly in any modern web browser

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 How to Run the Project

1. Download or clone the project.
2. Open the project folder.
3. Double-click **index.html** or open it in any modern browser such as Google Chrome, Microsoft Edge, or Firefox.
4. Start popping balloons and try to achieve the highest score.

---

## 🎮 How to Play

- Click on the balloons before they disappear.
- Each balloon popped earns **1 point**.
- Balloons appear faster as your score increases.
- The game lasts **30 seconds**.
- When the timer reaches zero, the game ends.
- Click **Play Again** to restart.

---

## 🎯 Game Objective

The objective of the game is to score as many points as possible by popping balloons within the given time limit while keeping up with the increasing game speed.
